SQL Intelligence Sorgu İnceleyici

Gelişmiş analitik görünümü oluşturan optimize SQL betiği

PostgreSQL 16.2 Yürütme: 142ms Taranan Satır: 2.418.902 İndeks: btree_orders_cust
-- sales_cohort_and_vip_aggregation.sql 
WITH CustomerFirstOrder AS (
    SELECT 
        customer_id,
        DATE_TRUNC('month', MIN(order_date)) AS cohort_month
    FROM core_warehouse.fact_sales
    WHERE order_status = GROUP BY 1
),
CustomerActivity AS (
    SELECT 
        f.customer_id,
        c.cohort_month,
        DATE_TRUNC('month', f.order_date) AS activity_month,
        SUM(f.total_net_amount) AS revenue_contribution,
        COUNT(DISTINCT f.order_id) AS lifetime_orders
    FROM core_warehouse.fact_sales f
    JOIN CustomerFirstOrder c ON f.customer_id = c.customer_id
    WHERE f.order_date >= '2024-01-01'
    GROUP BY 1, 2, 3
)
SELECT 
    ca.customer_id,
    dim.company_name,
    dim.city,
    SUM(ca.revenue_contribution) AS total_revenue,
    SUM(ca.lifetime_orders) AS total_orders,
    ROUND(SUM(ca.revenue_contribution) / NULLIF(SUM(ca.lifetime_orders), 0), 2) AS aov,
    DENSE_RANK() OVER (ORDER BY SUM(ca.revenue_contribution) DESC) AS revenue_rank
FROM CustomerActivity ca
LEFT JOIN core_warehouse.dim_customers dim ON ca.customer_id = dim.customer_id
GROUP BY 1, 2, 3
ORDER BY total_revenue DESC
LIMIT 20;

Optimizasyon & İndeks Açıklaması

Bu sorgu, core_warehouse.fact_sales üzerindeki (order_date, order_status, customer_id) bileşik BRIN indeksini kullanır. Partition pruning sayesinde yalnızca 2024 blokları taranmakta olup bellek tüketimi 18MB ile sınırlandırılmıştır.
